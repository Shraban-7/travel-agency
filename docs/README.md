# Travel Agency Website — Project Docs

Bangladeshi agency: Hajj & Umrah, Foreign Employment (Middle East / Europe / Malaysia / others), Study Abroad, Tour Packages, Visa & Ticketing.

## Read in this order
1. `REQUIREMENTS.md` — what to build (business + functional + non-functional)
2. `ARCHITECTURE.md` — stack, structure, modules, conventions
3. `DATABASE.md` — tables, columns, relations
4. `DESIGN.md` — UI/UX, pages, components, Bangla/English
5. `ROUTES.md` — public, admin, API routes
6. `SECURITY.md` — data protection, compliance
7. `PHASES.md` — build order, milestones, checklists
8. `TESTING.md` — test plan
9. `DEPLOYMENT.md` — hosting, env, backups
10. `DEBUG.md` — troubleshooting playbook
11. `CONTENT.md` — content the client must provide
12. `CLAUDE.md` — rules for AI-assisted coding on this repo

## Stack (one line)
Laravel 11 + Inertia.js + React 18 + Tailwind + MySQL 8. Bilingual (Bangla default, English).
